# リファクタリング計画（REFACTOR_PLAN）

`/refactor` が読み書きする。**外部の振る舞い・DB／API の契約・画面仕様を変えない**改善だけを並べる
（振る舞いを変えるものは `tasks/BACKLOG.md` のタスクにする）。

- 方針: 1単位 = 1コミット（WIP=1）。各単位で `<型検査> && <lint> && <テスト>` を通す
- ステータス: `todo` / `doing` / `done` / `blocked`。上ほど高優先（価値 × 低リスク）
- 監査だけなら `/refactor --audit`。見つけた候補をここへ並べ、承認を得てから着手する
- 完了した単位は消さず `done` にし、次に効く学び（「同じ判断が3か所にあった」等）を「現況」へ1〜2行残す
