# 要件詳細の分け方

PRD の「何を作るか」を、「どう作るか」に落とした文書をここに置く。1文書1担当範囲。

| 文書（例） | 担当範囲 |
|---|---|
| `01_system_architecture.md` | 技術スタック、環境変数、認証、監視 |
| `02_data_model.md` | テーブルの列・制約・保持期間 |
| `03_auth_billing.md` | 登録・ログイン、課金、利用枠 |
| `04_jobs.md` | 定時処理、ジョブ、通知 |
| `05_api.md` | API・サーバー処理の入出力、エラー、認可 |
| `06_screens.md` | 画面ごとの仕様、文言の方針 |

各文書は冒頭に `| バージョン | v1.0 |` `| 更新日 | YYYY-MM-DD |` の表、末尾に変更履歴を持つ。
