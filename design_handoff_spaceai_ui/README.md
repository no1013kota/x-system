# Handoff: Space AI — 全画面UIリデザイン

## 概要
X運用自動化SaaS「Space AI」のWebアプリ全画面（8画面）の高忠実度(hi-fi)UIデザイン。
既存の実装済みシステム（フロント・バックエンド開発済み）の**見た目だけ**をこのデザインに置き換えることが目的。機能・API・データフロー・ルーティングは変更しない。

## このバンドルのファイルについて
- `Space AI App.dc.html` + `support.js` は **HTMLで作られたデザインリファレンス（プロトタイプ）** です。そのままプロダクションコードとしてコピーするものではありません。
- タスクは「このHTMLが示す見た目・挙動を、**対象コードベースの既存環境**（使用中のフレームワーク・コンポーネント・スタイリング手法）で再現すること」です。
- ブラウザで `Space AI App.dc.html` を開くと動作確認できます（左ナビで画面切替。投稿作成画面は右上ピルで3ステート切替）。

## 忠実度
**High-fidelity（hifi）**。色・タイポグラフィ・余白・文言は最終品質。既存コードベースのライブラリ・パターンを使ってピクセルパーフェクトに再現してください。
ただし**文言・データはダミー**（@kenji_consult 等）。実装では既存システムの実データ・実文言にバインドすること。

### タイポグラフィ
- 日本語: **Noto Sans JP**（400/500/700）

- 絵文字は使用しない

### 形状・余白
- 角丸: カード/ボタン/入力 `8px`、チップ小 `6px`、ピル/トグル `9999px`

- アプリ全体 `min-width:1150px`（デスクトップ前提、狭幅は横スクロール）

## 画面一覧（8画面）

### 1. ホーム
- 挨拶H1＋日付・次回自動実行のサブテキスト
- トライアルバナー（`#f4e8f3`、残り日数・課金開始日・「プランを管理」）
- **初期設定ガイド**カード: 進捗 `n/m 完了`＋グラデーション進捗バー、チェックリスト（完了=緑塗りチェック/未完=白丸＋「設定する」ボタン）。プランで項目が変わる（BYOK=7項目にAPIキー2項目を含む / プレミアム=5項目でキー不要）
- KPI 4カード（フォロワー数/今週の投稿/未確認の下書き/次回の自動実行）
- 2カラム: 最新ニュースdigest（インパクトバッジ＋タイトル1行＋時刻）/ 未確認の下書き＋今日の予定

### 2. 最新ニュース
- 分野タブ（すべて=黒地白字がアクティブ、他は白地ピル）
- 2カラムのニュースカード: カテゴリチップ＋「インパクト 高/中/低」バッジ＋時刻、タイトル(14px/700)、要約(12.5px)、フッターにソースdomain＋**「⚡すぐに投稿作成」**ボタン（`#f4e8f3`地・キー色文字）→ 投稿作成画面へ遷移
- 注記: ニュースは運営側取得・全ユーザー共通、生成は自プランのキー

### 3. 投稿作成（3ステート）
- 右上にステート切替ピル（1.パターン選択・入力 / 2.生成中 / 3.確認・編集）— 実装ではこれは実際の生成フローの状態遷移
- **ステート1**: パターンカード6枚グリッド3列（P-1選択中=1.5px紫枠＋チェック、P-5=opacity .55＋「初期提供停止」バッジ＋not-allowed）。入力フォーム（参考URL・追加指示、いずれも任意）、画像生成トグル＋OpenAI/Geminiセグメント、キー注記（プランで文言分岐）、**「スレッドを生成する」＝グラデーションボタン**
- **ステート2（生成中）**: カード上端3pxグラデーションバー、スピナー＋タイトル、進捗ステップ4行（完了=緑チェック/実行中=紫パルス/待機=灰丸）、シマースケルトン、「中断する」
- **ステート3（確認・編集）**: 左=ポストカード連続（`n/4`チップ＋役割ラベル＋文字数 `82/140`＋ミニ進捗バー、本文、1ポスト目のみ16:9画像プレースホルダ＋再生成/削除、各カードに編集・再生成アクション）/ 右=sticky列（投稿前チェック3項目・追加指示で再生成・**「今すぐ投稿する」グラデーション**＋「下書きに保存」）

### 4. 下書き・スケジュール
- 同意バナー（緑 `#f0f9ee`、同意日・即時停止可・「自動投稿を停止する」）
- スケジュールカード: スロット行 = 時刻(Inter 18px/700)・曜日チップ・パターンチップ・画像有無・モードバッジ（自動投稿=紫淡 / 下書きまで=灰）・編集アイコン・トグル。OFF行は opacity .55。注記: 9:00〜22:00・30分刻み
- 下書きカード: 行 = P-xチップ＋自動/手動バッジ＋日時＋メタ、本文2行clamp、右に「編集」「投稿する」(紫solid)・削除アイコン。注記: 本日の投稿 6/50 安全上限

### 5. 分析・改善
- ヘッダ右に「提案を更新」(紫solid)＋「本日の更新 残り1回」
- KPI 4カード → フォロワー推移カード（SVG折れ線: 線 `#7d1f75` 2.5px・面 `#f4e8f3`・グリッド線 `rgba(0,0,0,.05)`・最新値ラベル、30日/90日ピル）
- 2カラム: 投稿別実績テーブル（列: 投稿/型/投稿日時/インプ/いいね/RP/プロフ、数値右揃えtabular-nums、スレッドは合算表示の注記）/ 改善提案カード（電球アイコン＋提案3件、各に灰色の「根拠：…」ボックス、**表示専用**の注記）

### 6. 設定（2カラムのセクションカード群）
- 連携Xアカウント（接続済みバッジ・再連携・破線「追加」ボタン、プラン上限表記 1/1 or 1/3）
- APIキー: **BYOKプランのみ表示**（X API Client IDマスク表示＋接続確認済み、生成AI 3行: Claude=文章・リサーチ選択中/OpenAI=画像割当/Gemini=未登録、取得手順ガイドリンク）。**プレミアム時は差し替え**（「APIキー登録は不要です」カード＋利用上限メーター4枠: 通常投稿62/200・URL付き8/20・文章生成41/100・画像9/20）
- 学習（参考アカウント2/3・参考投稿6/10・過去投稿100件、再取り込み30日制限はボタンdisabled風）
- 通知設定（トグル4行、メール＋アプリ内）
- ペルソナ（灰色ボックスに本文）・発信テーマ（6チップ複数選択＋自由入力チップ）・トーン＆マナー（3行のピル選択）・NG設定（削除×付きチップ＋破線追加）
- プラン・お支払い（次回請求日・「Stripeカスタマーポータルを開く」、カード情報非保持の注記）

### 7. ベースmdファイル
- **通常プラン時はロック画面**（鍵アイコン・説明・「mdプランにアップグレード」）
- md/プレミアム: 左=エディタカード（ファイル名 `base_kenji_consult.md` のツールバー＋monospace 12px本文、編集モードチップ）/ 右=編集履歴（日時＋内容＋「この版に戻す」）とプロンプト編集リスト（P-1〜P-6＋画像、既定/カスタム/停止中バッジ＋編集）
- ヘッダ右に「編集履歴」「保存する」

### 8. 料金プラン
- 3カード（¥500/¥1,000/¥2,980、mdに「人気」バッジ、プレミアムにグラデーション「キー登録不要」バッジ、現在プラン=紫枠＋disabledボタン）
- BYOK注意の警告バナー（黄）
- 登録フローカード: 4ステップ（番号丸＋説明）＋ BYOK/プレミアムの初期設定分岐2カード

### T. トースト・エラー
- **T-1 成功トースト** / **T-2 エラートースト**: 幅380px・白カード・左端3pxカラーバー（緑`#4ea836`/赤`#c2333c`）・アイコン＋太字タイトル＋本文リンク＋×。右下表示、成功は5秒で自動消滅、エラーは手動クローズ
- **T-3 前提不足エラー**: 生成・投稿実行時に表示。warning見出し＋黄色ボックス内に不足項目リスト（未登録/未設定の明記）＋「設定画面へ」ボタン（ホームの初期設定ガイドと対応）
- **T-4 上限到達バナー**: 画面上部固定。日次50件到達=黄（翌日0:00 JST再開）/ プレミアム月間上限=紫淡（毎月1日リセット・「利用状況を見る」）

### E. 空状態（カード内padding 44px・中央寄せ・灰円アイコン48px）
- **E-1 下書きなし**: 「投稿を作成する」primary＋「スケジュールを設定」ghost
- **E-2 ニュース該当なし**: フィルタ変更の案内＋「表示設定を変更」
- **E-3 分析データなし**: 「改善提案は投稿5件から」の説明＋「最初の投稿を作成する」

### H. 投稿履歴（H-1・下書き画面から遷移）
- テーブル列: 投稿日時/型チップ/自動・手動/内容1行/形式（スレッド(n)・単発）/ステータス
- ステータス: 成功=緑バッジ＋「Xで表示」リンク / **ロールバック済み**=黄バッジ＋黄色サブテキスト（「3/4ポスト目の送信に失敗 — 投稿済み2件をロールバック削除（下書きは保持）」）

## 状態管理・分岐
- `screen`: 8画面の切替（実装では既存ルーティングに対応付け）
- `cstep`: 投稿作成の 入力→生成中→編集（実装では生成APIの実状態）
- `plan`: `normal | md | premium` — 影響箇所: ナビのmd鍵アイコン / 初期設定ガイド項目 / 設定のAPIキーセクション差替＋利用上限メーター / サイドバー利用量ミニバー / 生成キー注記 / mdロック画面 / アカウント上限 / 料金の現在プラン表示
- `trialDaysLeft`（0で全トライアルUI非表示）、`setupComplete`（trueでガイド非表示）
