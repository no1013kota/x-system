## 参考にした実例・型（リサーチ 2026-09-01）

- **情報整理/まとめ発信型**: 1行のつかみ→見やすい構造→箇条書き。読む負荷が下がり滞在時間が延び、有益性で保存・シェアが増える（[addness](https://addness.co.jp/media/twitter-imp/)）。
- **連載・定期型はフォロー動機を作る**: 「何をいつ出すか」が明確なアカウントはフォローされやすい（同上・連載予告型）。
- 運営者実例1（P-1）の「基準100なら…」のような**読者が比べられる数字への変換**は、まとめでも各件の1行に効く。

## 構造分解

| 要素 | 効果 |
|---|---|
| 「今週の◯◯まとめ」＋ひと言総括 | 定期性の宣言（毎週の型として認知される）＋今週の空気が1行で分かる |
| 箇条書き＝目次（件名＋数字） | メインだけで今週の概要が分かる＝保存される形（P-3と同じ判断） |
| 1件1ポスト＋自分の見立て1文 | ニュースの転載で終わらせない。見立てが「この人のまとめ」の価値 |
| 来週の注目点＋問い | 次週への予告（定期読者化）と会話の起点 |

## プロンプト設計の判断

1. **重要度順を明記** — news_digestは新着順で来るため、並び替えを指示しないと時系列の羅列になる。
2. **「読者にとっての意味」を各件に用意する手順を追加** — 要約の羅列と解説の分かれ目。
3. **総括の一言を追加** — 「今週は◯◯が動いた週」。まとめ全体に背骨が通る。
