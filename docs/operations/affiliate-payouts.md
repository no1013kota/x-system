# 運用メモ: 招待報酬の銀行振込オペレーション

| 項目 | 内容 |
|---|---|
| バージョン | v1.1 |
| 更新日 | 2026-08-25 |
| 関連 | 要件03「招待プログラム」／要件02 §3.22〜3.26／正本 [招待プログラム 実装仕様書](../cp/invite_cp.md)（T-M8-174/176） |

招待報酬は**月末締め・翌月末支払・振込手数料980円（利用者負担）・最低5,000円**。
振込予定（Payout）の作成までは自動で、**銀行振込そのものと支払記録だけが運営者の作業**。
道具はコマンド1つ（`npm run affiliate:payouts`）に畳んである（原則2・3）。

## 1. 毎月の流れ

| いつ | 何が起きるか | 運営者の作業 |
|---|---|---|
| 毎日（自動） | 支払いから30日の確認期間を過ぎた報酬が「確定前」→「受取可能」になる | 不要 |
| 月初（自動） | 前月締めの振込予定（Payout）が作られる（受取可能が5,000円以上＋口座登録済みの利用者だけ。未満・口座なしは翌月へ繰越） | 不要 |
| 月中〜月末 | — | **下の§2で振込→支払記録**（期限＝当月末） |

自動処理は `scheduler_tick` 相乗り（`cron_runs` の `affiliate_batch` で冪等。claimと本処理は同一トランザクションなので、失敗した回は次のtickが自動で再試行する）。

## 2. 振込の手順（月1回・期限は当月末）

```bash
# ① 未払いの振込予定を一覧する（金額・期限・相手のメール）
npm run affiliate:payouts

# ② 1件ずつ詳細を見る（振込先口座の全桁はここでだけ復号表示される）
npm run affiliate:payouts -- --show <id>

# ③ 銀行で振り込む（表示された「振込予定額」= 報酬合計 − 手数料980円）

# ④ 支払いを記録する（束ねた報酬が「支払済み」になり、利用者の「受取可能」が0になる）
npm run affiliate:payouts -- --paid <id>
```

- **②で相手のメールアドレスを必ず確認する。** 別メールでの実質的な自己招待は機械検知していない（要件03）。招待者本人と思われる場合は振り込まず、利用規約第19条（不正の無効化）に基づいて対応する。
- ②〜④の間に返金（Refund）が入った場合、振込予定額は自動で引き直される。**④は記録の直前に、振込予定の額といま束ねている報酬の合計を突き合わせる**（T-M8-301）。食い違っていたら**記録せずに止まり**、いくつからいくつへ変わったかを表示する——黙って直すと、実際に振り込んだ額と台帳が食い違ったまま残るため。止まったら `--show` で見直し、実際に振り込んだ額で処理する。日を跨ぐなら②を見直してから振り込む。
  - 2026-08-25 まで、この突き合わせは**実装されていなかった**（正本には書かれていたが、突き合わせる関数はテストからしか呼ばれていなかった）。
- staging/本番のDBに対して実行するには、`DATABASE_URL` をその環境の値にして実行する（`.env.local` のローカル値のままだとローカルDBを見る）。

## 3. 例外と対応

| 事象 | どうなるか | 対応 |
|---|---|---|
| 受取可能が5,000円未満 | Payoutは作られず翌月へ繰越 | 不要 |
| 口座未登録 | Payoutは作られず翌月へ繰越（画面が登録を促す） | 不要 |
| 振込前に全額返金された | Payoutの金額が自動で引き直される。手取りが0以下になったらPayoutごと取消（`canceled`）され、①の一覧から消える | 不要（振り込まない） |
| **支払済みの報酬に返金が来た** | 自動では触らない。**Sentryに `affiliate-refund-paid` として届く** | 回収・次回相殺などを個別判断 |
| invoiceを解決できない返金 | Sentryに `affiliate-refund` として届く | 内容を確認（サブスク外決済などは対象外でよい） |
| 支払期限（当月末）を過ぎそう | 何も壊れないが利用規約上の約束に遅れる | 早めに§2を実施 |

## 4. 会計の分離（税理士へ渡すとき）

Payoutは `gross_amount`（報酬合計）・`fee_amount`（手数料980円）・`net_amount`（実振込額）を
**分けて保存**している（報酬から手数料を引いた1本値にしない・invite_cp.md §10）。
月次の集計はDBの `affiliate_payouts` / `affiliate_commissions` が正本。
