今後追加予定の新機能
- 設定 > プロンプトに、プロンプト公開トグル（デフォルトではオン）と公開する時に自分のアカウント名とアカウント画像を公開するかのトグル（デフォルトではオフ）を用意したいです。そのトグルによってプロンプト集で公開されるかどうかと公開時にアカウント名とアカウント画像を公開するかどうかが決まるようにしてください。
- プロンプト集は新規登録後のユーザーしか見れないようにしてください。プラン登録していなくても見ることはできます。
- プロンプト集にはブックマーク機能をつけてください。ブックマーク数もしくは新しい順で並びが変わるようにしてください。
