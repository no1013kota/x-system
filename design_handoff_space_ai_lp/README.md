# Handoff: Exos AI ランディングページ

## 概要
X（旧Twitter）運用を自動化するWebアプリ「Exos AI」のLP（1ページ）。読後のゴールは「無料で始める」→会員登録。ターゲットは非エンジニアの個人事業主・フリーランス。

## このバンドルについて
同梱の `Space AI LP v2.dc.html` は **HTMLで作られたデザインリファレンス**（意図した見た目と挙動を示すプロトタイプ）であり、本番コードとしてコピーするものではない。タスクは、このデザインを既存の **Next.js (App Router) + Tailwind** 環境で再現実装すること。

実装先の必須ルール（リポジトリ側の要件）:
- `src/app/page.tsx` を置き換える形で実装する
- **価格・プラン名・上限値は `src/lib/plans.ts` から参照する**（LPに直書きしない）。ただし画面上の表記はこのREADMEの文言と一致させること
- フッターの法務3リンク（利用規約／プライバシーポリシー／特定商取引法に基づく表記）は既存の `LegalFooter` コンポーネントを使う（URLを自前で書かない）
- 外部CDN・外部画像は使わない。フォントは `next/font`（Inter + Noto Sans JP）が使えるならそれを、使えないならシステムフォールバックで可

## 忠実度
**hifi**。色・タイポ・余白・角丸・影・文言は最終版。ピクセル再現を目指す。図版（アプリモック・ミニチャート等）はすべてCSS/DOMで描かれており、画像アセットは存在しない。

## インタラクション & モーション
- **スクロール出現は実装しない**（2026-08-09・T-M8-76 で廃止）。初版は `[data-reveal]` を初期 `opacity:0` にして IntersectionObserver で解除する設計だったが、**JSのロード失敗・CSPブロック・JS無効のいずれでもLPがヘッダーだけの白紙になる**（実測）。LPは会員登録の唯一の入口で、サーバーは200・テストも緑のため運営者は気付けない。JS不要の `animation-timeline: view()` も画面外を `opacity:0` に保つ点は同じで、印刷が空白になり「ページ全体が読めるか」を検証できないため採用しない。**LPの内容は常に不透明で表示する。**
- **prefers-reduced-motion: reduce**: 残る装飾アニメーション（生成ループ・フロート）を無効化
- **生成ループ（7s infinite）**: バー幅 6% → 88%(58%時点) → 100%(66%〜)。ラベル「生成中… 通常60〜90秒」⇄「生成が完了しました。内容を確認してください」（--brand）をクロスフェード。keyframes名 `sai-bar` / `sai-lblA` / `sai-lblB` をHTML参照
- **フロートカード**: `translateY(0→-7px→0)` 7s ease-in-out infinite
- **ホバー**: カード=浮き影へ .25s／主CTA=`--brand-hover` + translateY(-1px) + `0 4px 16px rgba(125,31,117,0.25)`／副CTA=`#ecd9ea`／navリンク=--brand
- **FAQ**: ネイティブ `<details>`。open時に「＋」を `rotate(45deg)` .25s
- スムーススクロール、アンカー先セクションに `scroll-margin-top:76px`
